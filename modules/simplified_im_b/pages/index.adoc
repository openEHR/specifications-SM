= {spec_title} [.spec-status.spec-status-development]#{spec_status}#

A reduced-complexity data model intended for integrators and application developers who need to work with openEHR data over REST without implementing the full Reference Model. SIM-B trades some expressiveness for a flatter, more directly serialisable structure, lowering the tooling and implementation overhead for common integration scenarios. SIM-B types map directly to JSON-serialisable structures, making them suitable for use with the openEHR simplified REST format without an intermediate transformation step.

== Purpose

This document describes the Simplified Information Model 'B' (SIM-B) format, a simplified form of the {openehr_rm}[openEHR RM^], intended to be used to generate the simplified JSON Data Template (sJDT) format. The SIM-B model is designed to enable easier creation of openEHR content (i.e. Compositions etc).
